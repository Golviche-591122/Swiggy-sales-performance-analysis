# 🍽️ Swiggy Sales Analysis – Excel

## 📌 À propos du projet

Dans le cadre de mon apprentissage en analyse de données, j’ai réalisé ce projet autour des données de **Swiggy**, une plateforme indienne de livraison de repas.

L’objectif était de partir d’un jeu de données déjà structuré et d’utiliser **Microsoft Excel 2024** pour analyser les performances commerciales et construire un tableau de bord interactif.

Pour réaliser cette analyse, j’ai principalement travaillé avec les **tableaux croisés dynamiques**, les **graphiques croisés dynamiques** et les **segments**, afin d’explorer les données sous différents angles et d’en tirer des indicateurs utiles.

---

## 🎯 Objectifs

À travers ce projet, je voulais notamment répondre à plusieurs questions :

- Quel est le niveau global des ventes ?
- Comment les ventes évoluent-elles au fil du temps ?
- Quelle catégorie de nourriture génère le plus de ventes ?
- Quels États et quelles villes sont les plus performants ?
- Comment évoluent les ventes, les commandes et les évaluations ?
- Comment présenter toutes ces informations dans un dashboard simple et interactif ?

---

## 🛠️ Outils utilisés

- **Microsoft Excel 2024**
- Tableaux croisés dynamiques
- Graphiques croisés dynamiques
- Segments (Slicers)
- Formules Excel
- Visualisation des données

---

## 📊 Les principaux KPI

J’ai sélectionné plusieurs indicateurs pour avoir une vue rapide des performances :

| KPI | Résultat |
|---|---:|
| Total des ventes | 53,01 M |
| Note moyenne | 4,34 |
| Valeur moyenne d'une commande | 268,51 |
| Nombre d'évaluations | 5,59 M |
| Nombre de commandes | 197,43 K |

Ces indicateurs constituent la partie principale du résumé présenté dans le dashboard.

---

## 📈 Analyses réalisées

### Évolution des ventes

J’ai utilisé des tableaux croisés dynamiques pour analyser les ventes selon différentes périodes :

- par mois ;
- par semaine ;
- par jour.

Cela permet de mieux observer les variations de l'activité commerciale.

### Analyse par type de nourriture

J’ai également comparé les ventes entre les deux catégories :

- **Veg**
- **Non-veg**

Les résultats montrent que la catégorie **Veg représente environ 64 % des ventes**, contre environ 36 % pour la catégorie Non-veg.

### Analyse géographique

Une autre partie du projet consiste à analyser les ventes selon la localisation.

J’ai notamment étudié :

- les ventes par État ;
- les 5 villes générant le plus de ventes ;
- la répartition géographique des performances.

### Analyse trimestrielle

J’ai aussi comparé les performances par trimestre en prenant en compte :

- les ventes ;
- les commandes ;
- les évaluations.

Parmi les trimestres affichés dans le dashboard, **Q2 présente le niveau de ventes le plus élevé**, avec environ 19,90 M.

---

## 🎛️ Le dashboard

L'objectif final du projet était de regrouper les principaux résultats dans un **dashboard interactif**.

Pour rendre l'exploration plus simple, j'ai ajouté plusieurs segments permettant de filtrer les résultats selon :

- le mois ;
- la catégorie ;
- le restaurant.

L'utilisateur peut ainsi sélectionner différents critères et voir directement leur impact sur les indicateurs et les graphiques.

## 💡 Quelques résultats intéressants

Cette analyse m'a notamment permis de constater que :

- les ventes totales atteignent environ **53,01 M** ;
- la note moyenne est de **4,34** ;
- la catégorie **Veg** représente la plus grande part des ventes ;
- certaines villes et certains États concentrent une part importante des ventes ;
- les performances varient selon les périodes étudiées.

Au-delà des résultats, ce projet m'a surtout permis de mieux comprendre comment utiliser Excel pour passer de données brutes à une **analyse orientée business**.
